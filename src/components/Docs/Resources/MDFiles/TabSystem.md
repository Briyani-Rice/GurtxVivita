# Tab System

## Introduction

In the tab system, you can add new tabs and switch between open views.

## Shortcuts

| Shortcut | Action |
| --- | --- |
| `⌘T` | New tab |
| `⌘W` | Close current tab |
| `Ctrl+Tab` | Next tab |
| `Ctrl+Shift+Tab` | Previous tab |
| `⌘1` – `⌘9` | Jump to tab 1–9 |
| `⌥⌘I` | Open Dev Tools |
