# Command Bar
## What is it?
The command bar is at the center top of the window and serves as a quick and easy way to carry out commands.
## How to use it?
Type in the command name first and then type in the following arguments for the command
## What are the different types of commands?
The command bar has different commands. Below are some example of the commands: 
* Search - Search up an item
* Help - Pulls up the documentation tab
* Settings - Pulls up the settings tab
