# Roommap

## Introduction

The room map shows the VIVITA layout using the map reference provided for the space.

## Areas

The map includes the main areas from the layout:

- White Space
- Tinkering Studio
- Work Tables
- Pegboard Storage
- VIVI Shelving
- Stairs
- VIVISTUDIO
- Roof Terrace

## How to use it

Click or tap an area on the map to see what materials are stored there.

Use the `+`, `-`, and `Reset` controls to zoom and reset the map view.

## Material details

When an area is selected, the side panel shows:

- Area name
- Material name
- Material description
- Quantity and unit
